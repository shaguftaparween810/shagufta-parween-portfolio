# Shagufta Parween — Developer Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local static server from this folder:
   - Python: `python -m http.server 5500`
   - Then visit `http://localhost:5500`

## Included
- Responsive portfolio with About, Skills, Projects, Experience, Education and Contact sections.
- Downloadable resume in `assets/Shagufta_Parween.pdf`.
- Links to the featured Inventory Management System demo and GitHub repository.
- Contact link opens the visitor's email application using `mailto:`.

## Before publishing
- Confirm every external project URL is still active and that you are comfortable displaying it publicly.
- Add your LinkedIn profile URL and any additional public code repositories if desired.
- The inventory dashboard visual is a conceptual portfolio preview, not a live screenshot.
- For a working contact form that submits without opening an email app, connect a backend or a form service.
- Deploy the folder to GitHub Pages, Netlify, Vercel or any static hosting provider.
